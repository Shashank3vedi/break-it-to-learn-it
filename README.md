# Break It To Learn It

Hands-on web-security walkthroughs. I break deliberately-vulnerable apps — **DVWA** and the **PortSwigger Web Security Academy** — and document exactly how each attack works and how to defend against it: how to find it, how to exploit it in the lab, and how to fix it.

> Educational content on intentionally vulnerable labs only. Nothing here targets any system without authorization.

---

## What you'll find here

Each writeup follows the same simple format:

1. **The bug** — what it is, in one line
2. **Find it** — how to spot it
3. **Break it** — the exploitation, step by step (in the lab)
4. **Fix it** — the remediation
5. **Mapped to** — OWASP Top 10 / CWE
